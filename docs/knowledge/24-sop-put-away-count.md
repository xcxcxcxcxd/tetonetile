# Put away and count

*Poster for: the warehouse entrance.*

## Put away

1. Open **Scan → Put away / move**.
2. Scan the **pallet label**.
3. Read the suggested positions - same lot first, then same product, then empty.
4. Take the pallet there and scan the **location label** on the beam or lane.
5. Check the beep and the green message. Next pallet.

## Count a location

6. Open **Count** (or scan a location → Count it) and scan the **location label**.
7. Scan **every unit label** you see there; correct the boxes if they differ.
8. Press **Finish count** and read the result: confirmed, found, corrected, missing.

## Rules

- Never move a pallet without scanning it. Put away within the shift.
- One pallet = one lot. Never top up with boxes from another lot.
- Nothing leaves **quarantine (Q)** without a QC release.
